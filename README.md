# Damien Silva — Engineering Portfolio

Portfolio personnel responsive, au style sombre et technique, destiné à présenter :
- le parcours en génie mécanique ;
- le projet Vhélio (conception, optimisation, tôlerie et simulation) ;
- les compétences en CAO, ANSYS et fabrication ;
- Silva Prints et le prototypage par impression 3D.

## Aperçu local
Ouvrir `index.html` dans un navigateur. Le site est statique : HTML, CSS et JavaScript, sans dépendance de compilation. Une connexion Internet est nécessaire pour charger les polices Google Fonts ; le site reste lisible sans elles.

## Personnalisation avant publication
1. Remplacer `TON.EMAIL@EXEMPLE.CH` dans `index.html` par ton adresse professionnelle.
2. Vérifier le lien LinkedIn et ajouter l'URL exacte de ton profil.
3. Remplacer les illustrations schématiques par tes captures Creo, images de prototypes, photos d'atelier et captures ANSYS.
4. Compléter chaque fiche projet avec des données vérifiées et les documents que tu es autorisé à publier.
5. Vérifier qu'aucun document ne contient de données confidentielles, de coordonnées privées, de données d'entreprise ou d'informations non publiables.

## Structure
- `index.html` : page d'accueil et sections principales
- `styles.css` : identité visuelle responsive
- `script.js` : navigation mobile et année dynamique
- `projects/` : fiches détaillées des projets
- `assets/` : emplacement des images et fichiers de présentation

## Publier avec GitHub Pages
GitHub Pages permet d'héberger gratuitement un site statique depuis un dépôt GitHub public avec GitHub Free.

1. Créer un dépôt nommé `damiensilva0.github.io` sur GitHub.
2. Ajouter à la racine du dépôt les fichiers `index.html`, `styles.css`, `script.js`, ainsi que les dossiers `projects/` et `assets/`.
3. Dans le dépôt, ouvrir **Settings → Pages**.
4. Choisir la branche `main` et le dossier `/ (root)` comme source, puis enregistrer.
5. Une fois la publication terminée, le site devrait être accessible à `https://damiensilva0.github.io`.

Documentation officielle : https://docs.github.com/en/pages/quickstart
